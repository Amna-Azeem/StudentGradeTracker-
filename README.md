# Student Grade Tracker

## 📌 Project Overview

The **Student Grade Tracker** is a Java-based application designed to help teachers manage students' grades efficiently. It allows users to input students' names and their scores across multiple subjects, then calculates:

- Total, average, highest, and lowest scores.
- The student with the highest and lowest total marks.
- The highest scorer in each subject.

## 💻 Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Arrays/ArrayLists
- Scanner Class for User Input

## 🔧 Features

✅ Input student names and marks for multiple subjects.
✅ Calculate total and average marks.
✅ Identify the highest and lowest total scores.
✅ Determine the top scorer for each subject.
✅ Display results in a structured format.

## 🚀 How to Run

1. Clone the repository:
   ```sh
   git clone https://github.com/Amna-Azeem/StudentGradeTracker.git
   ```
2. Navigate to the project directory:
   ```sh
   cd StudentGradeTracker
   ```
3. Compile and run the program:
   ```sh
   javac StudentGradeTracker.java
   java StudentGradeTracker
   ```
4. Follow the on-screen instructions to enter student data and view results.
